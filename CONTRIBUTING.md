# Contributing

Useful contributions: reproducible agent behavior failures, clearer installation routes, missing decision branches, or better evaluation fixtures.

Please include:

- Agent, model, version and skill commit.
- Minimal task and available tools.
- Expected behavior and actual behavior.
- Sanitized transcript or reproducible steps.
- Proposed change and which acceptance scenario it addresses.

Keep the canonical skill in SKILL.md. PROMPT.md must match its body exactly. Preserve deep-only questioning, explicit approval, capability honesty and no automatic improvement cycles. Run `python3 validate.py` before submitting changes. Behavioral evidence is more valuable than generic claims. Do not include credentials, private code or personal data.

GrillPower is licensed under the [MIT License](LICENSE). Submit only contributions you have the right to license under these terms; preserve applicable third-party copyright notices.

For comparative claims, use the same model, task, starting files, permissions and evaluation criteria. Report the actual skill revisions, transcripts, pass/fail outcomes and token usage when exposed. Never use fake testimonials, fabricated install counts or star manipulation.
